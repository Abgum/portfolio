Smart Campaign Composer

Turns a marketer's request into an audience and SMS / email drafts. Built for a company's technical assessment and made public at their request.

  • Sends no message until a person approves. Supports scheduled sends, A/B variants and multiple languages.
  • Never runs LLM-generated audience rules directly: validates them, then compiles them to parameterized SQL.
  • Runs a PostgreSQL-based queue with row-level locking, retries, idempotency keys and a unique index, so no message is sent twice.
  • Checks consent twice: at approval and right before sending.
  • Shows live send status over SSE in a Vue 3 dashboard; ships Prometheus metrics and GitHub Actions CI.
